# Дневник питания и тренировок

Личный проект: учёт еды, расчёт калорий и БЖУ, программа тренировок,
отслеживание прогресса.

## Как пользоваться
Открыть **claude.ai/code**, выбрать этот репозиторий и просто
рассказывать, что ел и как тренировался. Голосом, текстом, фотографиями
блюд и меню — как удобно.

Всё остальное делает Claude: считает, записывает в файлы,
обновляет дашборд.

## Структура
```
CLAUDE.md         принципы работы — как вести проект
profile.md        антропометрия, цели, предпочтения
foods.md          справочник продуктов
plan.md           шаблон дня и целевые БЖУ
progress.md       вес, замеры, калории по дням
training.md       программа тренировок
training-log.md   журнал подходов
diary/            по файлу на каждый день
dashboard.html    дашборд, публикуется как артефакт
```

## Первый шаг
Скопировать текст из `ONBOARDING.md` и отправить первым сообщением.
